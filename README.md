# AiDevTV
AI DEV TV – Smart Launcher for Mobile and TV's

An all-in-one Smart TV and mobile entertainment ecosystem featuring a customizable  launcher, built-in file manager, web browser, media player, content publishing platform and remote content management. Discover free movies and OTT content, publish user and developer content, rotate displays and transform Smart TVs into remotely managed digital signage and billboard displays etc.


Key features to highlight in README:
- Custom Smart TV Launcher
- Android TV, Google TV and Mobile support
- Built-in File Manager
- Integrated Web Browser
- Built-in Media Player
- User and Developer Content Publishing
- Remote Content Publishing and Management
- Free Movies and OTT Content Discovery
- Screen Rotation and Display Orientation (Digital Signage and TV Billboard Mode)
- Remote TV Content Management etc.
